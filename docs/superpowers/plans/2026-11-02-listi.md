# Listi við hliðina á kortinu: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A list drawer on the left of the board (full screen under 1024 px) that shows the same items as the board, grouped like it, and whose row click glides the board to the card and opens the panel.

**Architecture:** The per card computation Board does today (tone, bucket, visible, fresh, label, mover) moves to a pure `cardModels` in `lib/cards.ts` that `BoardPage` runs once and hands to both `Board` and the new `ListDrawer`. The drawer is pure presentation over `listRows` in `lib/list.ts`. `Board` gains `reveal` and `peek` on its handle, and every fit now pads the free area (`freeRect` in `lib/geometry.ts`) so the list and the panel never cover what a fit shows. Open state and sort live in `localStorage` through `useListPrefs`, with an in-memory open state for the narrow layout.

**Tech Stack:** React 19, TypeScript, Vite 6, vitest, react-i18next, the `--hg-*` token layer in `src/vinnubord/vinnubord.css`. No new dependency, no migration, no CLI change.

**Spec:** `docs/superpowers/specs/2026-11-02-listi-design.md`

**Interfaces:**
- Produces, in `geometry.ts`:
  - `export type Padding = { top: number; left: number; right: number; bottom: number }`
  - `export const DEFAULT_PADDING: Padding = { top: 90, left: 40, right: 40, bottom: 60 }`
  - `fitAll(rects, viewport, padding: Padding)` and `fitWidth(rect, viewport, padding: Padding, maxZoom?)` read `padding.left` and `padding.right` where they read `sides` today
  - `export function parsePx(raw: string): number` ("460px" gives 460, " 16px " gives 16, "" or garbage gives 0)
  - `export const REVEAL_MIN_ZOOM = 0.8`
  - `export function freeRect(size: { w: number; h: number }, cover: { list: number; panel: number; sheet: boolean }, base: Padding = DEFAULT_PADDING): Padding` returns `{ top: base.top, left: base.left + cover.list, right: base.right + cover.panel, bottom: cover.sheet ? Math.max(base.bottom, size.h * SHEET_HALF) : base.bottom }` (`SHEET_HALF` imported from `./sheet`; the half sheet covers the bottom 45 % of the board, so the free area is what is above it)
  - `export function revealView(card: Rect, current: View, size: { w: number; h: number }, padding: Padding): View`: zoom `z` is `current.z` when `REVEAL_MIN_ZOOM <= current.z <= MAX_ZOOM`, else `REVEAL_MIN_ZOOM`; the card centre `(card.x + card.w / 2, card.y + card.h / 2)` maps to the free centre `(padding.left + (size.w - padding.left - padding.right) / 2, padding.top + (size.h - padding.top - padding.bottom) / 2)`.
- `useViewport.ts` imports `Padding` and `DEFAULT_PADDING` from `../lib/geometry` and re-exports `Padding` (Board and others import it from the hook today, keep that working).

### Task 3: List rows and preferences logic

**Interfaces:**

```ts
export type Sort = 'pack' | 'status' | 'updated'
export const SORTS: readonly Sort[] = ['pack', 'status', 'updated']
export type ListPrefs = { open: boolean; sort: Sort }
export const DEFAULT_LIST_PREFS: ListPrefs = { open: false, sort: 'pack' }
export function listKey(projectId: string): string            // `hg.list.${projectId}`
export function parseListPrefs(raw: string | null): ListPrefs  // json with open boolean and sort in SORTS; anything else gives the defaults field by field
export function serializeListPrefs(p: ListPrefs): string       // JSON.stringify
// The open state that applies: the stored one on a wide board, the in-memory one on a narrow board.
export function listOpen(prefs: ListPrefs, narrow: boolean, narrowOpen: boolean): boolean
export const BUCKET_ORDER: readonly (keyof Counts)[] = ['new', 'mine', 'others', 'build', 'parked']
export type ListRow =
  | { kind: 'pack'; id: string; name: string }
  | { kind: 'module'; id: string | null; name: string | null; color: string | null; count: number }  // null id: "Án módúls"
  | { kind: 'bucket'; id: keyof Counts; count: number }
  | { kind: 'item'; card: CardModel; moduleName: string | null }
export type ListRows = { rows: ListRow[]; count: number }      // count: item rows
export function listRows(cards: CardModel[], packages: Package[], modules: Module[], sort: Sort): ListRows
```

  Rules (spec 4.5, 4.6): only `visible` cards. `pack`: packages by `position`, modules by `position` within the pack (`packLayout` from `./layout`), a module row only when it has at least one card, a pack row only when it has at least one module row; items within a module by `BUCKET_ORDER.indexOf(bucket)` then `title.localeCompare(other, 'is')`; cards whose module is null or not in `modules` go last under one module row `{ id: null, name: null, color: null, count }`, with no pack row above it. `status`: a bucket row per bucket in `BUCKET_ORDER` that has cards, items within by `updated_at` descending then `id` ascending; `moduleName` set. `updated`: item rows only, same order, `moduleName` set. Cards with `bucket === null` are skipped in `status` (they are not on the board).
